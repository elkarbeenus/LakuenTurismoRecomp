Erste Version von **LakuenTurismoRecomp** – GT6 auf RPCS3 als eine AppImage für SteamOS.

**Neu gegenüber dem Original (Mabec-games v1.2 Beta 5):**
- Auto-Update direkt in der App: Beim Start wird nach neuen Versionen gesucht, ein Klick installiert sie (SHA-256-geprüft, Einstellungen und Spielstände bleiben).
- Festes, stabiles Preset für Ryzen 7 5800X3D + RX 6600 XT (B550, PCIe 4.0): 1080p, 150 % Auflösung, Sharper MLAA, Strict Rendering (AMD-Fix), ZCull-Queries aus, 60 FPS.
- Nur noch Linux/SteamOS, kein Windows-Build.

**Installieren:** `LakuenTurismoRecomp-x86_64.AppImage` laden, ausführbar machen, starten. Eigene GT6-ISO nötig.

RPCS3 wurde in GitHub Actions aus dem offiziellen Quellcode (Commit eee3f0f7) plus den GT6-Patches dieses Repos gebaut.
